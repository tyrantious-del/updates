# DOMINATORS v2 — Browser Combat Prototype

An original browser-based tactical action prototype inspired by the large-scale, class-driven feeling of classic online infantry combat games. It does not use copied names, art, maps, code, audio, or assets from Infantry Online.

## Start

1. Extract the ZIP.
2. Open the `DOMINATORS-v2` folder.
3. Double-click `PLAY_DOMINATORS_V2.bat`, or open `index.html` in Chrome, Edge, or Firefox.

No installation, server, npm packages, or internet connection is required.

## V2 highlights

- 14v14 battlefield with 27 autonomous soldiers
- Five classes: Vanguard, Medic, Engineer, Heavy, and Recon
- Three original operations with distinct layouts and atmosphere
- Domination and Frontline rule sets
- Friendly and hostile armored rovers
- Class abilities, grenades, deployable sentries, healing, shields, scans, and cloaking
- Reinforcement tickets, objective income, overtime, respawning, and match results
- Bot state machines with objective assignment, target evaluation, strafing, retreat, healing, and vehicle use
- Persistent rank, XP, career statistics, settings, and best scores using browser local storage
- Dynamic particles, lighting, screen shake, hit markers, synthesized sound, announcer cues, minimap, scoreboard, and kill feed
- Pause menu, difficulty selection, reduced motion option, and full control reference

## Controls

| Control | Action |
|---|---|
| WASD | Move / drive |
| Mouse | Aim |
| Left mouse | Fire |
| Right mouse | Focus / vehicle brake |
| R | Reload |
| G | Throw grenade |
| Q | Class ability |
| E | Enter or exit rover / interact |
| Shift | Sprint |
| Tab | Scoreboard |
| Esc | Pause |
| 1–5 | Select next spawn class |

## Notes

This is a single-player vertical slice with simulated multiplayer combat. The code is deliberately dependency-free and kept readable for future conversion to a networked authoritative server architecture.
